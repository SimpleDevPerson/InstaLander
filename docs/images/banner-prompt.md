# Banner InstaLander

Strumento: imagegen integrato. I quattro input sono i PNG in `docs/screenshots/`.

```text
Create a polished, wide landscape promotional banner for the Android Flutter app InstaLander using the FOUR supplied REAL APP SCREENSHOTS as immutable visual inserts.

Input order and roles:
1. report.png: exact screenshot insert for the Report phone.
2. timeline.png: exact screenshot insert for the Timeline phone.
3. whitelist.png: exact screenshot insert for the Whitelist phone.
4. reminders.png: exact screenshot insert for the Promemoria phone.

Most important: composite these actual supplied screenshots into the phone frames. Preserve their UI, text, icons, demo usernames, navigation bars, colors, and relative spacing. Do not invent, redraw, redesign, translate, remove, or replace interface elements. No fake substitute app screens. Only scale and clip screenshot corners to fit the frames. Keep each screen upright and frontal, without perspective distortion. Keep screenshot text as faithful as possible.

Composition: a premium editorial app showcase inspired by a row of four large rounded smartphones, with staggered heights. All four phones must be large, clearly visible and separate; generous breathing room. Place Report, Timeline, Whitelist, Promemoria in that order left to right. The center two phones sit slightly higher than the outer two. Slim matte charcoal-black rounded phone bezels, soft natural shadows, refined subtle highlights. Screens are the dominant visual focus. Avoid camera notches or status bars that cover UI. Do not add hands or photographic environments.

Background: deep charcoal/navy, tasteful large organic flowing shapes and softly glowing abstract blue, teal, and muted violet elements around the outer edges, with a tiny warm magenta accent echoing the app's Instagram-inspired icon. Decoration must never obscure the screenshots. A clean, elegant One UI / Material design mood. Flat decorative background, realistic restrained device shadows, crisp readable typography.

Text outside phones, exactly:
Main title at top left: "InstaLander"
Small line near title: "Report · Timeline · Whitelist · Promemoria"
A small discreet footer: "Anteprima con dati dimostrativi"
No other marketing copy, claims, extra names, numbers or watermarks.

Deliver one high-resolution landscape banner, preferably about 2400 x 1350, suitable for a GitHub README. Preserve all four smartphone screens and their navigation bars, leave enough bottom room for short labels beneath the phones if appropriate. Rounded outer banner corners are optional.
```
