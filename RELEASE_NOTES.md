# InstaLander 0.7.1

Novità rispetto a 0.7.0 (build 2008).

- Avvio più rapido con uno storico ampio. Il report prepara l’ultima importazione e la timeline calcola le differenze alla prima apertura.
- Il report carica solo le schede vicine alla vista quando gli annunci non sono visibili. Il salvataggio della whitelist viene elaborato in background.
- L’importazione JSON usa la data dei file originali se il giorno coincide. Apre il calendario se le date differiscono o ne manca una.
- Le build profile possono mostrare gli annunci di prova dopo il consenso.

## Download

- InstaLander-0.7.1-universal.apk per tutti i dispositivi supportati.
- APK dedicati per ARM64, ARM a 32 bit e x86 a 64 bit.
- InstaLander-0.7.1.aab per la distribuzione tramite store.
- SHA256SUMS.txt con i checksum dei cinque pacchetti.

Android minimo: 8.0 (API 26).
