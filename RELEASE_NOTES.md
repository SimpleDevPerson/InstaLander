# InstaLander 0.7.4

Novità rispetto a 0.7.3 · build 2011.

- Rimossi i permessi Android di accesso a tutti i file e di lettura/scrittura generale dell'archiviazione.
- JSON e ZIP vengono importati tramite il selettore documenti Android, con accesso temporaneo in sola lettura ai soli file scelti.
- La selezione multipla dei JSON, l'importazione ZIP e la lettura della data dei documenti restano disponibili.

## Download

- InstaLander-0.7.4-universal.apk per tutti i dispositivi supportati.
- APK dedicati per ARM64, ARM a 32 bit e x86 a 64 bit.
- InstaLander-0.7.4.aab per la distribuzione tramite store.
- SHA256SUMS.txt con i checksum dei cinque pacchetti.

Android minimo: 8.0 (API 26).
